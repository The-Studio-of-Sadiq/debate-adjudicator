# Changelog

Notable changes, newest first. The project follows the phases in
[PLAN.md](PLAN.md); versions map to phases until the first public release.

## Unreleased

- Debate formats are definition files (`packages/core/src/formats/`):
  speeches, timing, teams and scoring in one place, validated by the tests,
  with a template to copy. Ballots read their scoring from the format.
- New format: World Schools (WSDC).
- UADC comes in two timings: **UADC 7-7-7-4** (the existing preset, renamed)
  and **UADC 5-5-5-3** (5-minute speeches, POIs 1:00–4:00, 3-minute replies).
- 45 formats from the Debatekeeper format library (MIT), converted by
  `npm run formats:import`: Australs, Canadian and American Parliamentary, BP
  5 and 6 minutes, NSW, Auckland, Spanish, Polish, Greek and more. 49 formats
  in all.
- Home: the featured formats as buttons, plus a searchable list of every
  format grouped by region, showing level, summary and prep time.
- Bell settings group speeches by kind in formats that have more than
  substantives and replies (e.g. Canadian rebuttals).
- Website: a format library with a page for each format.
- Translations: `npm run i18n:new` starts a language from the English
  dictionary and registers it; `npm run check:i18n` reports each language's
  coverage and catches wrong keys and placeholders. The language picker shows
  native names.
- Guides for translating and adding formats, on the website too, and issue
  templates for translation and format requests.

- Brand identity: "The House" logo (Government's solid bench, Opposition's
  open bench, the Speaker's chair between them) and the "Parliament" type
  system: Instrument Serif for titles and motions, Inter for everything else,
  with tabular figures on the clock. Fonts are bundled for offline use.
- New app icon, Android adaptive and themed icons, light and dark splash
  screens, favicon and Windows window icon, all generated by `npm run brand`.
- Brand guide in `docs/brand/`.
- Website: a static, indexable site (landing page, formats from the app's
  presets, docs generated from `docs/wiki`), with sitemap, robots.txt,
  structured data, social preview image and a GitHub Pages workflow.

## [0.5.0] – Phase 5: adjudicator tools

- Flow notes on the chair's timer, stamped with the speech time.
- Speaker names per seat, filled in when a seated debater is approved.
- Ballots: BP (50–100, ranks and 3/2/1/0 points from totals) and UADC
  (70–80, replies 35–40 in 0.5 steps, winner and margin); invalid or tied
  ballots can't be marked final.
- PDF round report with ballot, timings, interruptions, notes and optional
  transcripts (share sheet on Android, save dialog on Windows).
- Notes, ballots and transcripts stay on the chair's device.
- Monochrome light and dark themes with a "match device" option.
- All UI text translatable (i18next) with a language picker; network error
  reasons are sent as codes. **Devices must all run this version.**

## [0.4.0] – Phase 4: transcription

- Offline Whisper transcription on Windows (transformers.js) and Android
  (whisper.rn plus a MediaCodec decoder module).
- Optional OpenAI-compatible cloud provider with automatic offline fallback.
- Transcripts synced to audio: tap a line to play from there.

## [0.3.0] – Phase 3: interruption audio

- A debater's phone records their accepted POI or their POO/POP and sends it
  to the chair over the local network, retrying after reconnects.
- Windows app saves rounds and recordings to disk immediately (no loss on crash).
- Android QR scanning via Google's code scanner; `debate://` join links.

## [0.2.0] – Phase 2: local multi-device

- QR or typed-code join, chair approval, roles (timekeeper, debater, wing, viewer).
- Clock sync so every device shows the same time and rings bells together.
- POI/POO/POP raised and answered from joined devices; automatic readmission
  after a dropped connection.

## [0.1.0] – Phase 1: single device

- BP and UADC presets, timer with phase display, scheduled and manual bells,
  bell editor, per-speech recording, round history and review.
