## Full description (1275/4000)

```
Debate Adjudicator は、チェアのスマートフォン1台でディベートのラウンドを進行できるアプリです。タイマー、ベル、POI はローカルの Wi-Fi を通じてルーム内のすべてのスマートフォンに届きます。アカウントもインターネット接続も必要ありません。

BP（British Parliamentary）、UADC（Asian Parliamentary、7-7-7-4 と 5-5-5-3）、World Schools (WSDC) に対応し、さらに Australs、Canadian、American Parliamentary、学校やリーグの形式など 45 の形式を収録しています。スピーチの時間、ベル、POI の受付時間はすべて編集できます。

タイムキーピング
• プロテクトタイム、POI 受付中、まとめ、グレースピリオド、超過の各フェーズがひと目でわかるスピーチタイマー
• 予定したベルも手動のベルも、すべての端末で同時に鳴ります
• 検索できる形式の一覧と、編集できるベル設定

1つのルームに、すべてのスマートフォン
• ディベーター、タイムキーパー、ウィングジャッジは QR コードを読み取るか、短いコードを入力して参加
• 会場の Wi-Fi でも、スマートフォンのテザリングでも使えます
• チェアが端末ごとに承認し、役割と席を割り当てます

POI とポイント・オブ・オーダー
• ディベーターは自分のスマートフォンから POI、ポイント・オブ・オーダー、ポイント・オブ・パーソナル・プリビレッジを出せます
• POI はスピーカーが受けるか断るかを決め、それ以外はチェアが裁定します
• ポイントを聞いている間、タイマーは一時停止します

録音と文字起こし
• チェアのスマートフォンで各スピーチを録音
• 端末上でオフラインで文字起こし、またはご自身の API キーでクラウドサービス（ElevenLabs、OpenAI、Groq）を利用
• 英語に対応し、ベンガル語はクラウド経由で対応。文字起こしの行をタップすると、その部分を聞けます。

ジャッジング
• すべてのスピーチにタイムスタンプ付きのフローノート
• すべての形式に対応したバロット。チームの順位や勝者はスピーカーの点数から決まります
• ラウンドのレポートを印刷できる PDF で書き出し

プライバシーに配慮した設計
メモ、バロット、録音、文字起こしはチェアの端末に保存されます。アカウント、広告、トラッキングは一切ありません。

17 の言語
英語、ベンガル語、スペイン語、フランス語、ポルトガル語、ドイツ語、ロシア語、トルコ語、ヒンディー語、中国語（簡体字）、日本語、韓国語、インドネシア語、マレー語、ベトナム語、アラビア語、ウルドゥー語に対応。アラビア語とウルドゥー語は右から左へのレイアウトで表示されます。

ライトテーマとダークテーマに対応。MIT License のもとで公開されている、無料のオープンソースアプリです。
```
