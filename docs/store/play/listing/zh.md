## Full description (898/4000)

```
Debate Adjudicator 让主裁用一部手机主持整场辩论比赛。计时器、铃声和质询（POI）通过本地 Wi-Fi 同步到房间里的每一部手机，无需账号，也无需联网。

专为英国议会制（British Parliamentary）、UADC（Asian Parliamentary，7-7-7-4 和 5-5-5-3）和世界学校辩论赛制（WSDC）打造，另有 45 种赛制，包括 Australs、Canadian、American Parliamentary 以及各类学校和联赛赛制。每段发言的时长、每个铃声和每个 POI 时段都可以编辑。

计时
• 清晰的发言计时器，分为保护时间、可提 POI、收尾、宽限时间和超时几个阶段
• 预设铃声和手动铃声在所有设备上同时响起
• 可搜索的赛制选择器，铃声方案可编辑

一个房间，所有手机
• 辩手、计时员和边裁扫描二维码（QR）或输入短代码即可加入
• 使用会场 Wi-Fi 或手机热点均可
• 主裁逐一批准设备，并分配角色和席位

质询与规程问题
• 辩手可在自己的手机上提出 POI、规程问题或个人特权问题
• POI 由发言人接受或拒绝，其余由主裁裁定
• 听取问题期间计时暂停

录音与转写文本
• 在主裁的手机上录下每段发言
• 在设备上离线转写，或使用你自己的 API 密钥通过云端服务转写（ElevenLabs、OpenAI 或 Groq）
• 支持英语，孟加拉语可通过云端转写。点按转写文本中的某一行即可收听该段录音。

评判
• 每段发言都有带时间戳的流程笔记
• 每种赛制都有评分表；队伍排名或胜方根据辩手分数得出
• 将比赛报告导出为可打印的 PDF

注重隐私的设计
笔记、评分表、录音和转写文本都保存在主裁的设备上。没有账号，没有广告，也没有跟踪。

17 种语言
英语、孟加拉语、西班牙语、法语、葡萄牙语、德语、俄语、土耳其语、印地语、简体中文、日语、韩语、印度尼西亚语、马来语、越南语、阿拉伯语和乌尔都语，其中阿拉伯语和乌尔都语采用从右到左的布局。

提供浅色和深色主题。免费开源，采用 MIT License。
```
